# TrustLens 接入示例

三个示例都是**可直接跑的完整工程**，不需要任何配置。

| 示例 | 技术栈 | 启动命令 | 端口 |
|---|---|---|:---:|
| [`cdn.html`](./cdn.html) | 纯 HTML + CDN | 直接用浏览器打开即可 | — |
| [`vue3/`](./vue3) | Vue 3 + Vite | `npm install && npm run dev` | 5173 |
| [`react/`](./react) | React 18 + Vite | `npm install && npm run dev` | 5174 |

## 示例里能看到什么

打开后右下角有「🛡️ 数据透明」浮标。页面上有三个按钮，分别触发：

| 按钮 | 预期分类 | 说明 |
|---|---|---|
| 触发「已声明」接口 | ✅ 已声明接口 | `claims` 里声明过，展示站点自己写的用途说明 |
| 触发「未声明」提交 | ⚠️ 未声明的数据提交 | 携带了数据但站点没声明 —— 被标红 |
| 触发「第三方追踪」 | 🎯 第三方追踪 | 命中内置追踪域名表 |

提交体里写了 `filename`、`content`、`password` 等字段，
但打开面板你**只会看到字段名，看不到任何值** —— 这是组件的隐私底线，可以自己验证。

## 两种用法都演示了

示例同时展示了两种集成姿势：

1. **自带浮窗** —— 组件挂上就有 UI，零成本
2. **自建 UI** —— 把 `showFab` 设为 `false`，通过 `ref` 取 `getSummary()` / `getGrade()` 自己渲染

页面上的统计卡片和等级文案，就是用 `ref` 读出来自己渲染的，不是组件自带的。

## 关于 vite.config.js

示例用 `resolve.alias` 把 `trust-lens-*` 直接指向本地源码，
改组件代码即时生效，不用先 `npm run build`。

`mockApi` 插件是给示例造 `/api/*` 假接口用的，**接真实项目时删掉即可**。
